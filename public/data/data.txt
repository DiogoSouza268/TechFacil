Para adicionar celulares no supabase faça assim:
No painel do Supabase, clique em SQL Editor → New query.

Cole o modelo abaixo, preenchendo os dados do(s) celular(es) dentro dos colchetes [ ... ] (se quiser colocar mais de um de uma vez, basta separar cada { ... } por vírgula): 
segue prompt:




INSERT INTO celulares (nome, imagem, specs, detalhes_tecnicos, versoes)
SELECT
  item->>'nome',
  item->>'imagem',
  COALESCE(item->'specs', '{}'::jsonb),
  COALESCE(item->'detalhesTecnicos', '{}'::jsonb),
  COALESCE(item->'versoes', '[]'::jsonb)
FROM jsonb_array_elements(
  $json$
  [
    {
      "nome": "Apple iPhone 16 Pro",
      "imagem": "https://link-da-imagem-aqui.png",
